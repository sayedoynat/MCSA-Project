# 🛡️ Marshmallo Enterprise MSSP Infrastructure

An integrated enterprise infrastructure and Managed Security Service Provider (MSSP) simulation project. Designed to secure corporate networks, monitor real-time traffic, and centrally manage security policies across a Headquarters (HQ) and a branch environment based on MCSA principles.

---

## 🏗️ Project Architecture & Scope
* **Environment Simulation:** Multi-site topology featuring a Headquarters (HQ) and a dependent Branch.
* **Core Services:** Active Directory Domain Services (AD DS), DNS, DHCP, and Group Policy Objects (GPOs).
* **Standards:** Built upon modern enterprise networking and MCSA administrative standards.
